# DSE 化學批改助手（Chem Grader）

一個純前端（static）的 HKDSE 化學卷一批改站。上載答卷照片或 PDF，AI 按考評局評卷慣例逐點給分，輸出總分、準確率、逐題失分理由、弱項歸類與下一步建議。

- 無後端：所有請求由你的瀏覽器直接送到你指定的 LLM 端點
- 無資料庫：API Key 只存 localStorage；答卷不會被寫入倉庫
- 可部署：GitHub Pages 一鍵上線

## 目錄

```
index.html            頁面
styles.css            樣式
app.js                批改流程（提示詞組裝、PDF 轉圖、結果呈現）
data/rubric.json      評分準則（自行撰寫）
data/not-accept.json  措辭紅線庫（自行撰寫）
data/topics.json      DSE 化學課題樹（用於弱項歸類）
```

## 版權聲明（重要）

香港考試及評核局（HKEAA）的試題、評卷參考（marking scheme）受版權保護，**本倉庫不存放、也不再分發任何年份的試卷或評卷參考全文**。

本倉庫只包含由本項目自行撰寫的：

1. 評分準則（給分點類型、步驟分、帶遞誤差、有效溝通分）；
2. 常見措辭紅線（教學歸納，非任何 MS 原文）；
3. 課程課題樹；
4. 批改程式。

你手上的試卷與評卷參考，請在批改時即時上載／貼進「評卷參考」欄位使用。內容只會送到你設定的模型端點，**不會 commit 進倉庫**。這樣可以照樣用 2012–2026 全部年份練習，而倉庫本身保持合規。

## 使用

1. 填入 API Base URL、模型、API Key（支援任何 OpenAI 相容 `/chat/completions`）。
2. 上載答卷：JPG/PNG/PDF，可多張；PDF 會在本機轉頁面圖。
3. 選嚴格度：`嚴格（跟考評局）`／`標準`／`寬鬆`。
4. 有官方 MS 就貼進「評卷參考」欄，分數會明顯更貼近真評卷。
5. 按「開始批改」，可下載 Markdown 報告。

## 部署到 GitHub Pages

```
Settings → Pages → Source: GitHub Actions
```

或用 `Deploy from a branch`：`main` / `/ (root)`。

## 嚴格度如何影響給分

| 模式 | 行為 |
|---|---|
| 嚴格 | 只認 MS 明列答案或直接同義；明文「不接受」的措辭一律 0；數值須落在接受範圍 |
| 標準 | 接受 MS 的替代答案（`/`、`//` 所列）與語義等價改寫 |
| 寬鬆 | 概念方向正確即給分，主要用來診斷理解 |

## 已知限制

- 影像質素直接影響準確度：手寫潦草、反光、斜拍會拉低判分。
- 沒有官方 MS 時屬「推算批改」，會在總評註明。
- 一次建議 ≤ 40 頁，過多頁面請分卷上載。
- 模型不保證與考評局逐字一致；分數宜作診斷，不宜當成官方評級。
